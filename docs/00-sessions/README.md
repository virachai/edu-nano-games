# 00-sessions

## Purpose

This directory holds dated session notes — a running record of what was done, decided, and left open in each working session on **nano-games**.

## Naming Rule

All files must follow the format:

```text
00-{aa-bb-cc}-{YYYY-MM-DD}.md
```

- Example: `00-01-multi-agent-workflow-2026-09-16.md`
