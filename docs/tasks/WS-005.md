# WS-005 — Agent End-to-End Execution Dry Run

**Status:** READY  
**Priority:** P1  
**Depends On:** WS-004  
**Owner:** Local Agent  
**Evidence:** `docs/12-evidence/WS-005.md`

## Objective

Prove that the repository's local-agent execution workflow can complete one bounded task invocation end-to-end using the real runner and repository protocol.

## Scope

1. Use `scripts/agent-runner.sh` for one real execution attempt.
2. The agent must read `docs/AGENT_LOOP_RUNBOOK.md`, `docs/AGENT_RUNBOOK.md`, `docs/AGENT_RULES.md`, and `docs/BACKLOG.md`.
3. Select exactly one executable `READY` task.
4. Respect dependencies and execute only that task's scope.
5. Run verification and the repository self-check before handoff.
6. Record evidence and standard handoff.
7. Confirm runner logging and exit-code propagation.
8. Validate the no-ready-task stop condition: the agent reports `NO EXECUTABLE TASK` and stops when no executable READY task exists.
9. Do not mark WS-005 `DONE`; DWB105 remains reviewer.

## Constraints

- Do not execute multiple tasks in one invocation.
- Do not promote tasks to READY.
- Do not bypass dependencies.
- Do not declare reviewer approval.
- Do not silently repair invalid lifecycle/evidence state.
- Do not modify product logic for this protocol validation.
- Keep the execution bounded and reversible.

## Acceptance Criteria

- [ ] One real runner invocation completes with the expected protocol flow.
- [ ] Exactly one READY task is selected and executed.
- [ ] Verification and `agent:self-check` occur before handoff.
- [ ] Evidence contains commands, results, changed files, artifacts, and limitations.
- [ ] Runner log exists and records the invocation/result.
- [ ] Runner returns the agent's exit status.
- [ ] No-ready-task behavior is demonstrated or deterministically tested without leaving the repository in an unusable state.
- [ ] WS-005 is left at `EVIDENCE_COMPLETE`, not `DONE`.

## Verification

- `bash -n scripts/agent-runner.sh`
- `pnpm test`
- `pnpm agent:self-check -- WS-005`
- inspect runner log and handoff/evidence
- verify no-ready-task behavior through a safe isolated fixture or equivalent deterministic test

## Evidence Required

Create `docs/12-evidence/WS-005.md` with exact commands/results, changed files, runner log reference, acceptance-criteria evidence, blockers/limitations, and standard handoff.

## Completion

Agent may transition WS-005 to `EVIDENCE_COMPLETE` after implementation, verification, evidence, and self-check. DWB105 must review before `DONE`.
