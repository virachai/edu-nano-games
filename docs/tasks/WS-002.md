## Objective

Add one small automated regression test proving that the active local-agent runbook contains the core execution protocol required by this workspace.

## Scope

### In Scope

- Add `tests/agent-protocol-validation.test.js`.
- The test must read `docs/AGENT_RUNBOOK.md`.
- Assert that the runbook contains the required protocol concepts:
  - READY task selection

- Changing the agent protocol itself.
- Refactoring existing tests.
- Creating a new agent loop implementation.
- Modifying unrelated documentation.
