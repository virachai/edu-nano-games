# 02-01-web-game-architecture.md

## RFC-001: Web-Based Game Architecture

Covers the client-side architecture of the nano-games collection: a shared HTML5/CSS3/Vanilla JavaScript (ES6+) foundation with a common game shell (start screen, HUD, scoring, and game-over flow), per-game modules for each title, and an optional **Three.js** renderer for future 3D games.
