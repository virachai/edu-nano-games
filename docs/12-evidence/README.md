# 12-evidence

## Purpose

This directory holds evidence artifacts backing completed work — the proof (logs, screenshots, test output, links) that a task met its Definition of Done (see `00-governance/00-01-definition-of-done.md`).

## Naming Rule

All files must follow the format:

```text
12-{aa-bb-cc}.md
```

- Example: `12-01-mm-001-evidence.md`
