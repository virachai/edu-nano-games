- [x] Expected equivalent-fraction numerator is derived deterministically from source and target denominators — `expectedFraction()` computes `multiplier = targetDenominator / sourceDenominator` and `numerator = sourceNumerator * multiplier`; covered by "expectedFraction" tests.
- [x] Answer choices contain exactly one mathematically correct choice (GAME-001.1) — `createFractionQuestion()` throws `RangeError` unless exactly one choice equals `expectedFraction`; covered by the "no correct choice" and "more than one correct choice" tests.
- [x] Target denominator validity is enforced according to GAME-001.1 — `createFractionQuestion()` throws unless `sourceDenominator > 0`, `targetDenominator > 0`, and `targetDenominator % sourceDenominator === 0`; covered by the three "rejects ..." tests.

- [x] Score contribution follows the GAME-001.1 contract — `evaluateAnswer()` returns `scoreDelta: 1` for correct, `0` for incorrect; asserted directly in tests.
- [x] Focused automated tests cover correct conversion and meaningful invalid-answer cases, including denominator mismatch — 14 tests in `tests/fraction-forge.test.js`.
- [x] Semantic code has no dependency on browser rendering or UI state — `game.ts` imports nothing and defines only pure functions/types.
