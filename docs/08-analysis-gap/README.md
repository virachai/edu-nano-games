# 08-analysis-gap

## Purpose

This directory tracks the gap between the project's documented vision and the current repository state — what's specified vs. what's actually implemented, real-world execution risks, and the action plan to close the gap.

## Naming Rule

All files must follow the format:

```text
08-{aa-bb-cc}.md
```

- Example: `08-01-project-analysis-gap.md`
