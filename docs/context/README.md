# Task Context Packs

Context packs are stable execution context for local agents.

## Rule

`docs/tasks/` defines **what must be done**. `docs/context/` explains **what the agent needs to know to do it safely**.

Do not put new acceptance criteria or silently change task scope in a context pack.

## Naming

Use:

`docs/context/<TASK-ID>-CONTEXT.md`

Start from `TASK_CONTEXT_TEMPLATE.md`.
