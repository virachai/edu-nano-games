# 🎮 nano-games (Educational Mini-Games)

Welcome to **nano-games**, a collection of small educational mini-games (Nano Games) built to make learning fun and accessible for students from **elementary school through high school**. This project is driven and co-developed by **Freebuff (AI Coding Agent)**.

---

## 🚀 Game Collection

- **⚡ [Game 1] Fun Vocabulary Matching Game (For: Early Elementary - Upper Elementary)**
  - **Subjects:** English / Basic Science
  - **Details:** A card-flipping game that matches pictures with vocabulary words, helping to train memory and observation skills.
- **🚀 [Game 2] Math Guardian Spaceship (For: Upper Elementary - Middle School)**
  - **Subjects:** Mathematics (basic arithmetic and equations)
  - **Details:** Pilot a spaceship and shoot the meteor that shows the correct answer to earn points.
- **🧪 [Game 3] Chemistry Quiz Adventure (For: Middle School - High School)**
  - **Subjects:** Science (chemistry and the periodic table)
  - **Details:** An analytical quiz game that uses simulated scenarios to progress through levels.

---

## 🛠️ Tech Stack

The games in this project are designed as **Web-based Games** so students can play them instantly on a computer, tablet, or smartphone — no extra installation required:

- **HTML5 & CSS3** - For the structure and colorful game interfaces
- **Vanilla JavaScript (ES6+)** - For game controls, concepts, and logic
- **Three.js** _(optional)_ - For games that need 3D rendering
